# ПР3. Ответы на контрольные вопросы

## 1. Чем x += 5; отличается от x = x + 5;? Есть ли разница в результате?
Ничем не отличается. Это аналогичные записи, результат будет один.

## 2. В чём разница между x++ и ++x, если результат сразу используется в выражении (например, передаётся в Console.WriteLine)?
x++ сначала выводит, а потом увеличивает переменную, а ++x сначала увеличивает, а потом выводит.

## 3. Какой тип данных всегда получается в результате оператора сравнения (==, <, >= и т.д.)?
bool

## 4. Что такое «короткое замыкание» в && и ||? Приведите свой пример, где это имеет практическое значение.
Короткое замыкание это когда программа заканчивает свое выполнение раньше проверки каждого условия, потому что результат уже очевиден.
Например, в клуб пускают по вип пропуску или если я есть в списке гостей. Если я имею вип пропуск, нет смысла искать меня в списке, я и без этого уже допущен.

## 5. Расставьте приоритет для выражения 10 - 2 * 3 + 4 / 2, посчитайте вручную, а затем проверьте кодом.
Сначала выполнятся умножение и деление по порядку, а затем вычитание и сложение также по порядку. У меня получилось 6. В коде тоже получилось 6.
